# Historical coursework

These are the original IBM capstone notebooks and saved figures/metrics from the earlier course submission. They retain their source notices and are preserved for provenance. Their model scores use the old evaluation protocol and are not the portfolio's validated results.

The supported workflow is `python -m spacex.train` from the repository root. Read `results/metrics.json` and the root README for current results. Archived notebooks are not part of the automated checks; data paths and external course services may require changes to rerun them.
